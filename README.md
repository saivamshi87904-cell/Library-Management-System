# Library Management System (C++)

## Objective

This project is a console-based Library Management System developed using C++. It helps manage books, issue and return operations, and search functionality using Object-Oriented Programming and File Handling.

## Features

* Add new books
* Display all books
* Search books by title or author
* Issue books
* Return books
* File handling for permanent storage
* Menu-driven system

## Technologies Used

* C++
* Object-Oriented Programming (OOP)
* File Handling
* Console Application

## Outcome

The system efficiently manages library records and allows users to perform book-related operations in a simple and structured way while maintaining persistent storage.
